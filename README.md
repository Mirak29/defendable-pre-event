# Defendable — pre-event extract

This repository is an **extract of Defendable 1.0**, a private repository that
existed before the Meta Global AI Developer Hackathon. It holds only the 122
files that the hackathon project builds on, **exactly as they were** at the last
pre-event commit of Defendable 1.0: `c7bc119` (2026-09-29). Nothing here was
written or changed during the event.

The work of the hackathon lives in its own repository,
[defendable-hackathon](https://github.com/Mirak29/defendable-hackathon): its `setup.sh` downloads this
extract at a pinned commit, applies the changes made during the event
(`patches/pre-event.patch`) and adds the files created during the event.

On its own, this extract is not a complete app: it is the starting point the
hackathon code was built on.
